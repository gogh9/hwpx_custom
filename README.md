# hwpx-form-preserve

한글 문서(.hwpx)를 **서식 그대로** 살려서 작성·편집하는 Claude 스킬입니다.

학교에서 쓰는 계획서, 학습지, 평가지, 공문, 가정통신문 서식을 올리면, 그 서식의 그림·글자 모양·문단 모양·줄 간격·내어쓰기·표·수식을 그대로 둔 채 내용만 채우거나 문항과 항목을 늘립니다.

## 할 수 있는 일

- **서식 파악**: 서식 파일의 용지, 여백, 다단, 문단·글자 모양, 표 칸과 빈칸, 수식, 글상자, 그림을 정리해서 보여 줍니다.
- **서식 그대로 채우기**: 그 자리에 있던 글자 모양 그대로 글자를 넣습니다. 수식 안의 숫자와 분수도 바꿉니다.
- **복제로 늘리기**: 문항, 번호 항목, 대단원, 표 행이 더 필요하면 서식에 있는 것을 복제해서 늘립니다.
- **한 단어 넘김 자동 조정**: 마지막 줄에 한 단어만 넘어가면 그 줄 본문의 자간을 줄여 한 줄로 맞춥니다. 번호("1. ")는 그대로 둡니다.
  - 새로 쓴 문장뿐 아니라, 올린 원본에 이미 있는 넘김도 한글이 저장한 줄 배치로 찾아서 고칩니다.
  - 수식이 섞인 문장(수학 학습지의 비, 분수 등)도 됩니다.
  - 자간을 -12보다 더 줄여야 하면 고치지 않고, 필요한 자간 추정치와 문장 줄이기 안을 알려 줍니다.
- **내어쓰기 + Shift+Enter 목록**: "￭ 제목 ↵ • 항목" 같은 목록을 서식과 같은 방식으로 씁니다.
- **전후 비교**: 기존 서식 정의, 그림, 바탕쪽이 바뀌지 않았는지 점검합니다.

## 설치

### Claude 앱 (웹·데스크톱)

1. **[hwpx-form-preserve.zip 내려받기](https://github.com/gogh9/hwpx_custom/raw/main/hwpx-form-preserve.zip)**
   - 저장소 첫 화면의 "Code → Download ZIP"으로 받으면 폴더가 한 겹 더 생겨서 그대로 올리면 인식되지 않을 수 있습니다. 위 링크의 zip을 쓰세요.
2. Claude의 스킬 설정에서 zip 파일을 업로드합니다.

### Claude Code

`hwpx-form-preserve` 폴더를 `~/.claude/skills/` 안에 복사합니다.

```bash
git clone https://github.com/gogh9/hwpx_custom.git
cp -r hwpx_custom/hwpx-form-preserve ~/.claude/skills/
```

## 사용법

1. 한글 서식 파일(.hwpx)을 첨부하고 요청합니다.
   - 예: "이 서식으로 ○○ 연수 운영 계획서 만들어 줘"
   - 예: "이 평가지에서 2번 문제 숫자를 바꾸고 6번 문항을 하나 더 만들어 줘"
2. 결과 파일을 한글에서 열어 확인합니다.

자주 쓰는 서식은 구글 드라이브에 `계획서_기본서식.hwpx`처럼 이름에 "기본서식"을 넣어 두세요. 그러면 첨부하지 않아도 찾아서 씁니다. 이 기능은 Claude에 구글 드라이브가 연결돼 있어야 합니다.

## 예시 서식

[`examples/계획서_기본서식.hwpx`](examples/계획서_기본서식.hwpx)는 연수 운영 계획서 예시 서식입니다. 학교 정보와 일정은 "○○"로 비워 두었습니다.

- 대단원 막대(Ⅰ~Ⅴ), 내어쓰기 10pt 번호 항목, "￭ 제목 ↵ • 항목" 일정표 같은 이 스킬의 특징이 잘 드러나는 서식입니다.
- 처음 써 보실 때 이 파일을 첨부하고 "이 서식으로 ○○ 연수 운영 계획서 만들어 줘"라고 요청해 보세요.
- 자기 학교 양식으로 바꿔 쓰려면 한글에서 고친 뒤, 구글 드라이브에 이름에 "기본서식"이 들어가게 저장해 두면 됩니다.

## 알아 둘 점

- **.hwp(구형)는 처리하지 못합니다.** 한글에서 "다른 이름으로 저장 → .hwpx"로 바꿔서 쓰세요.
- **최종 확인은 한글에서 해야 합니다.** Claude는 한글 화면을 직접 그려 볼 수 없어서, 줄 나눔·쪽 넘김·수식 크기는 계산으로 예측합니다.
- **줄 나눔 예측은 함초롬바탕·함초롬돋움 기준**으로 맞췄습니다. 다른 글꼴은 오차가 더 클 수 있습니다.
- **할 수 없는 작업:** 세로 병합이 있는 표의 행 추가, 그림 교체, 머리말·꼬리말·누름틀 편집은 지원하지 않습니다.
- **글꼴은 문서에 들어 있지 않습니다.** 열어 보는 PC에 서식의 글꼴이 설치돼 있어야 합니다.
